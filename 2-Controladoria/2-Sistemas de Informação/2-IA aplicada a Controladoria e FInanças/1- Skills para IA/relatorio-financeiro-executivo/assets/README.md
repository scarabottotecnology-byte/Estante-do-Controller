# Assets — Relatorio Financeiro Executivo

## template-base.html
Template HTML completo de referência baseado no relatório ITTS SERO (Budget 2026 — Grupo Oficial Farma).

Contém todos os componentes implementados e prontos para reusar:
- Sistema de design completo (CSS custom properties dark theme)
- Capa com ticker de KPIs
- Cards KPI com delta indicator
- DRE em grid de colunas por período
- Cards de canais com barra de participação animada
- Tabela de preços/margens com filtros por linha de produto (JS)
- Painéis de mão de obra / FOPAG
- Cards de investimentos
- FCF timeline em grid
- Executive Summary (3 colunas: positivos | riscos | recomendações)
- Footer executivo
- Animações fadeUp escalonadas

**Como usar:** Ao gerar um novo relatório HTML, referenciar este template e adaptar:
1. Dados e valores
2. Seções necessárias (remover as que não se aplicam)
3. Paleta de cores se for cliente externo
4. Nome da empresa e período na capa

O template original está no histórico de conversa do usuário Jefferson (ITTS SERO Budget 2026).
